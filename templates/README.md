## Shared conventions

- **Frontmatter first.** Every entry has `id`, `type`, `title`, `tags` and `key_insight`. Keys below the `generated by prep build` comment are rewritten on every build; edit the keys above it.
- **Headings:** one `#` title, then `##` sections. Never skip a level.
- **Spoilers** (solutions, answers, follow-ups) go in `<details>` blocks.
- **The attempts table** sits between the `prep:attempts` markers and is generated from `data/attempts.csv`.
- **File names** are lowercase kebab-case. Problem numbers are zero-padded to 4 digits (`0146-lru-cache.py`); dated logs start with the date (`2026-11-15-codesignal-gca.md`).
